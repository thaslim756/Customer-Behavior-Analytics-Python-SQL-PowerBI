# 📊 Customer Behavior Analytics Dashboard

The Customer Behavior Analytics Dashboard is a Data Analytics project designed to analyze customer purchasing behavior, sales, revenue, subscription status, demographics, and customer ratings.

This project follows an end-to-end data analytics process, from data loading and cleaning using Python to SQL analysis and interactive visualization using Power BI.

---

## ✨ Project Features

- Customer behavior analysis
- Sales and revenue analysis
- Category-wise analysis
- Age group analysis
- Subscription status analysis
- Gender analysis
- Shipping type analysis
- Customer rating analysis
- Exploratory Data Analysis (EDA)
- SQL-based data analysis
- Interactive Power BI dashboard

---

## 📌 Key Performance Indicators (KPIs)

- Number of Customers
- Average Purchase Amount
- Average Review Rating
- Subscription Status

---

## 📈 Dashboard Summary

The dashboard provides an interactive overview of customer behavior and purchasing patterns.

It helps identify sales performance, revenue contribution, customer age-group trends, subscription behavior, and product category performance.

## 🔍 Key Insights

- Total customers analyzed: **3.9K**
- Average purchase amount: **$59.76**
- Average review rating: **3.75**
- Subscribed customers: **7.3%**
- Non-subscribed customers: **92.7%**
- Clothing generated the highest revenue among the categories.
- Customer sales and revenue were analyzed across different age groups.
